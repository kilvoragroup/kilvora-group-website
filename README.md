# KILVORA GROUP — Website institucional

Next.js (App Router) · React · TypeScript strict · Tailwind CSS · Vitest.

## Começar

```powershell
npm.cmd install
Copy-Item .env.example .env.local   # preencher apenas localmente
npm.cmd run dev
```

Abrir http://localhost:3000.

## Verificação

```powershell
npm.cmd run verify   # tipos, lint, formatação, testes e build
```

Regras de arquitectura e limites de execução: ver [CLAUDE.md](CLAUDE.md).
